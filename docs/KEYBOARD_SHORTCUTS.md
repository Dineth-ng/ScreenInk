# Default keyboard shortcuts

Change them on the home Keyboard shortcuts tab, then Apply. Escape stays available.

| Action | Shortcut |
| --- | --- |
| Laser pointer | L |
| Freeze / Live | F |
| Drawing / Pointer (global while overlay is open) | Ctrl+Space |
| Magnifier | M |
| Text | T |
| Numbered steps | N |
| Spotlight | S |
| Activate drawing (global) | Ctrl+Alt+D |
| Pen | P |
| Arrow | A |
| Rectangle | R |
| Highlighter | H |
| Eraser | E |
| Undo | Ctrl+Z |
| Redo | Ctrl+Y |
| Clear all | Ctrl+Shift+X |
| Close overlay | Esc |
| Capture full screen | Ctrl+Shift+S |
| Capture region | Ctrl+Shift+R |
