# Changelog

## 1.0.0 — local release candidate, not published
- Tool-shaped cursors for all drawing tools and effects; Brush is the default pen style.
- Green/white vector branding and About dialog.
- General, annotation and screenshot preferences; opt-in Windows startup.
- Validated per-user preferences and configurable overlay/export dimming.
- History limited to 100 actions and a 32 MiB estimated retained geometry budget.
- Optional bounded diagnostics without screen data or exception message text.
- Display geometry changes safely close the overlay.
- Maintained PyInstaller spec, version-generated metadata, per-user Inno installer.
- Artifact-only Windows CI, MIT license and release testing documentation.
